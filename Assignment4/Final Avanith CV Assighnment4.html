# ✅ TASK 1: Custom Dataset Class for CIFAR-10 + Visualization

import torch
from torch.utils.data import Dataset, DataLoader, Subset
from torchvision import datasets, transforms
import matplotlib.pyplot as plt
import numpy as np

# 1️⃣ Transform
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])

# 2️⃣ Custom Dataset Wrapper
class CIFAR10Dataset(Dataset):
    def __init__(self, cifar_dataset):
        self.data = cifar_dataset
    def __len__(self):
        return len(self.data)
    def __getitem__(self, idx):
        image, label = self.data[idx]
        return image, label  # (image_tensor, integer_label)

# 3️⃣ Load CIFAR-10 + wrap it
full_train = datasets.CIFAR10(root='./data', train=True, transform=transform, download=True)
full_test  = datasets.CIFAR10(root='./data', train=False, transform=transform, download=True)

train_subset = Subset(CIFAR10Dataset(full_train), list(range(600)))
test_subset  = Subset(CIFAR10Dataset(full_test),  list(range(200)))

train_loader = DataLoader(train_subset, batch_size=32, shuffle=True)
test_loader  = DataLoader(test_subset, batch_size=32, shuffle=False)

# 4️⃣ Visualization: show 6 (image, label) pairs
classes = full_train.classes

    imgs, labels = next(iter(loader))
    plt.figure(figsize=(10, 2))

Task 2: Feature Extractor and Contrastive Loss¶

a. Introduction and Objectives¶

The objective of this task is to design a feature extractor (encoder) that maps CIFAR-10 images to a fixed-size embedding vector. These embeddings are used in a Siamese network for comparing image similarity. We also integrate ContrastiveLoss to guide the training such that similar images are close in the embedding space and dissimilar ones are far apart.

b. Implementation with Justification¶

We implemented a lightweight custom CNN called SiameseCNN. This model has three convolutional layers followed by ReLU activations and MaxPooling. The final convolutional output is processed using AdaptiveAvgPool2d to reduce spatial dimensions, followed by a Linear layer to produce a 128-dimensional embedding.

The model supports both single-image encoding (forward(x)) and paired-image encoding via the helper method compute_siamese_feature(img1, img2).

We used the ContrastiveLoss from PyTorch Metric Learning with pos_margin=0.0 and neg_margin=1.0. This configuration ensures that the model only penalizes similar pairs that are far apart and dissimilar pairs that are too close.

c. Results and Analysis¶

A sanity check using torch.randn(2, 3, 32, 32) confirmed that the model produces output embeddings of shape [2, 128], which satisfies the task's fixed-length requirement. This confirmed the encoder's functionality before training.

d. Discussion of Findings¶

Our CNN encoder provided a flexible and compact architecture that integrates well with metric learning workflows. Unlike large pre-trained models, this custom CNN allows for complete control and faster iterations. The use of ContrastiveLoss introduced an effective way to differentiate between similar and dissimilar samples using distance margins.

e. Future Work¶

Future improvements could involve experimenting with deeper CNNs, adding dropout or batch normalization layers for regularization, or switching to more advanced architectures like MobileNet or ResNet if GPU resources are available.

# ✅ TASK 2 (Custom CNN): Embedding Model + ContrastiveLoss

import torch
import torch.nn as nn
from pytorch_metric_learning.losses import ContrastiveLoss

# 1️⃣ Define the custom CNN encoder
class SiameseCNN(nn.Module):
    def __init__(self, embedding_dim=128):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=3, padding=1),  # (B, 32, 32, 32)
            nn.ReLU(),
            nn.MaxPool2d(2),                             # (B, 32, 16, 16)

            nn.Conv2d(32, 64, kernel_size=3, padding=1), # (B, 64, 16, 16)
            nn.ReLU(),
            nn.MaxPool2d(2),                             # (B, 64, 8, 8)

            nn.Conv2d(64, 128, kernel_size=3, padding=1),# (B, 128, 8, 8)
            nn.ReLU(),
            nn.AdaptiveAvgPool2d((1,1))                  # (B, 128, 1, 1)
        )
        self.flatten = nn.Flatten()
        self.project = nn.Linear(128, embedding_dim)     # Final projection

    def forward(self, x):
        features = self.encoder(x)                       # (B, 128, 1, 1)
        flat = self.flatten(features)                    # (B, 128)
        return self.project(flat)                        # (B, embedding_dim)

    def compute_siamese_feature(self, x1, x2):
        f1 = self.forward(x1)
        f2 = self.forward(x2)
        return f1, f2

# 2️⃣ Instantiate model and loss
model = SiameseCNN(embedding_dim=128)
contrastive_loss = ContrastiveLoss(pos_margin=0.0, neg_margin=1.0)

# 3️⃣ (Optional) Sanity check
sample_input = torch.randn(2, 3, 32, 32)
with torch.no_grad():
    output = model(sample_input)
print("✅ Output shape:", output.shape)  # Expect (2, 128)

Task 3: Metric Learning with Sampler and Miner¶

a. Introduction and Objectives¶

In this task, we aim to optimize metric learning using two critical strategies: smart sampling and hard mining. Specifically, we incorporate MPerClassSampler to ensure batch diversity and PairMarginMiner to extract only informative pairs from the batch. The goal is to make training more efficient by focusing the model’s learning on difficult or ambiguous examples.

b. Implementation with Justification¶

We used MPerClassSampler with m=2 to ensure each batch has at least two samples per class. This enabled the formation of positive and negative pairs within each batch. A batch size of 20 was chosen, resulting in approximately 30 batches per epoch for our 600-sample subset.

To avoid computing contrastive loss on easy pairs (which contribute little to learning), we integrated PairMarginMiner. This miner identifies hard positives (same label, far apart) and hard negatives (different labels, close together). Only these pairs are passed to the contrastive loss function.

The model was trained for 5 epochs on CPU. The average loss per epoch steadily decreased, indicating stable learning. The final model was stored as improved_model for later use in Task 4.

c. Results and Analysis¶

Training took under a minute per epoch and loss values declined consistently. Sampler and miner integration led to focused learning, where only the most meaningful embeddings contributed to loss and gradient updates. This helped reduce training noise and led to a more discriminative embedding space.

d. Discussion of Findings¶

Using MPerClassSampler alone ensures diversity, but many sample pairs still contribute negligible gradients. Adding PairMarginMiner significantly improved training efficiency by focusing only on informative errors. This combination forms the backbone of many scalable metric learning systems.

e. Future Work¶

In future tasks, one could explore different miners such as TripletMarginMiner or MultiSimilarityMiner. Training with a larger dataset, or using curriculum mining (progressively increasing difficulty), could further improve performance.

# ✅ TASK 3: Training with Sampler + Miner + ContrastiveLoss

import time
import torch
import torch.optim as optim
from torch.utils.data import DataLoader, Subset
from torchvision import datasets, transforms
from pytorch_metric_learning.samplers import MPerClassSampler
from pytorch_metric_learning.miners import PairMarginMiner
from tqdm.notebook import tqdm

# 1️⃣ Dataset and transforms
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])

full_train = datasets.CIFAR10(root='./data', train=True, transform=transform, download=True)
subset_idx = list(range(600))  # fast training subset
train_subset = Subset(full_train, subset_idx)
labels_list = [train_subset[i][1] for i in range(len(train_subset))]  # correct label source

# 2️⃣ Sampler ensures batches contain both positive and negative pairs
sampler = MPerClassSampler(labels=labels_list, m=2, batch_size=20)

# 3️⃣ DataLoader with sampler
train_loader = DataLoader(train_subset, sampler=sampler, batch_size=20, num_workers=0)
print(f"Batches per epoch: {len(train_loader)}")  # should print 30

# 4️⃣ Miner: selects hard positive and negative pairs only
miner = PairMarginMiner(pos_margin=0.0, neg_margin=1.0)

# 5️⃣ Use the custom SiameseCNN model from Task 2
device = torch.device("cpu")
model = SiameseCNN(embedding_dim=128).to(device)
optimizer = optim.Adam(model.parameters(), lr=1e-3)
loss_fn = contrastive_loss  # from Task 2: ContrastiveLoss(pos_margin=0.0, neg_margin=1.0)

# 6️⃣ Training loop with tqdm
start_time = time.time()
for epoch in range(1, 6):
    total_loss = 0.0
    epoch_start = time.time()
    pbar = tqdm(train_loader, desc=f"Epoch {epoch}/5", ncols=80)
    for images, labels in pbar:
        images, labels = images.to(device), labels.to(device)
        embeddings = model(images)                      # 🔹 get embeddings
        hard_pairs = miner(embeddings, labels)          # 🔹 mine informative pairs
        loss = loss_fn(embeddings, labels, hard_pairs)  # 🔹 loss on selected pairs only

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
        pbar.set_postfix(loss=f"{loss.item():.4f}")

    print(f"→ Epoch {epoch} done — Avg Loss: {total_loss/len(train_loader):.4f} "
          f"— Time: {time.time() - epoch_start:.1f}s")

print(f"✅ Task 3 complete in {time.time() - start_time:.1f}s")

# Save trained model for Task 4
improved_model = model

# ✅ TASK 4: Compare Baseline vs Improved (k-NN + PCA + Confusion Matrix + Class Names in Legend)

import torch
import numpy as np
from torchvision import datasets, transforms
from torch.utils.data import DataLoader, Subset
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score, f1_score, confusion_matrix, ConfusionMatrixDisplay
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

device = torch.device("cpu")

# 1️⃣ Load train/test subsets (same 600/200 as before)
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])
train_dataset = datasets.CIFAR10(root='./data', train=True, transform=transform, download=True)
test_dataset  = datasets.CIFAR10(root='./data', train=False, transform=transform, download=True)

train_subset = Subset(train_dataset, list(range(600)))
test_subset  = Subset(test_dataset,  list(range(200)))

train_loader = DataLoader(train_subset, batch_size=64, shuffle=False)
test_loader  = DataLoader(test_subset,  batch_size=64, shuffle=False)

# 2️⃣ Train Baseline Model (no miner)
baseline_model = SiameseCNN(embedding_dim=128).to(device)
optimizer_base = torch.optim.Adam(baseline_model.parameters(), lr=1e-3)

print("▶ Training baseline model (no miner)...")
baseline_model.train()
for epoch in range(3):  # quick baseline train
    total_loss = 0.0
    for imgs, lbls in train_loader:
        imgs, lbls = imgs.to(device), lbls.to(device)
        emb = baseline_model(imgs)
        loss = contrastive_loss(emb, lbls)  # no miner here
        optimizer_base.zero_grad()
        loss.backward()
        optimizer_base.step()
        total_loss += loss.item()
    print(f"Epoch {epoch+1}/3 — Avg Loss: {total_loss/len(train_loader):.4f}")

# 3️⃣ Helper to extract embeddings
def extract_embeddings(model, loader):
    model.eval()
    all_embs, all_lbls = [], []
    with torch.no_grad():
        for imgs, lbls in loader:
            embs = model(imgs.to(device)).cpu().numpy()
            all_embs.append(embs)
            all_lbls.append(lbls.numpy())
    return np.vstack(all_embs), np.concatenate(all_lbls)

# 4️⃣ Get embeddings from both models
train_emb_base, train_lbl_base = extract_embeddings(baseline_model, train_loader)
test_emb_base,  test_lbl_base  = extract_embeddings(baseline_model, test_loader)

train_emb_imp,  train_lbl_imp  = extract_embeddings(improved_model, train_loader)
test_emb_imp,   test_lbl_imp   = extract_embeddings(improved_model, test_loader)

# 5️⃣ k-NN Evaluation with class-labeled confusion matrix
def eval_knn(train_e, train_l, test_e, test_l, label):
    cifar10_classes = ['airplane', 'automobile', 'bird', 'cat', 'deer',
                       'dog', 'frog', 'horse', 'ship', 'truck']
    
    knn = KNeighborsClassifier(n_neighbors=5)
    knn.fit(train_e, train_l)
    pred = knn.predict(test_e)
    
    acc = accuracy_score(test_l, pred)
    f1  = f1_score(test_l, pred, average='weighted')
    print(f"\n📊 {label} — Accuracy: {acc:.4f}, F1: {f1:.4f}")
    
    cm = confusion_matrix(test_l, pred)
    disp = ConfusionMatrixDisplay(confusion_matrix=cm, display_labels=cifar10_classes)
    fig, ax = plt.subplots(figsize=(8, 6))
    disp.plot(ax=ax, cmap='Blues', xticks_rotation=45)
    plt.title(f"{label} — Confusion Matrix")
    plt.grid(False)
    plt.show()

print("▶ k-NN Classification Comparison:")
eval_knn(train_emb_base, train_lbl_base, test_emb_base, test_lbl_base, "Baseline (No Miner)")
eval_knn(train_emb_imp,  train_lbl_imp,  test_emb_imp,  test_lbl_imp,  "Improved (With Miner)")

# 6️⃣ PCA Visualization with Class Names in Legend
def plot_pca(embeddings, labels, title):
    cifar10_classes = ['airplane', 'automobile', 'bird', 'cat', 'deer',
                       'dog', 'frog', 'horse', 'ship', 'truck']

    reduced = PCA(n_components=2).fit_transform(embeddings)
    plt.figure(figsize=(6, 5))

    for class_idx in range(10):
        idxs = labels == class_idx
        plt.scatter(reduced[idxs, 0], reduced[idxs, 1],
                    s=10, label=cifar10_classes[class_idx])

    plt.title(title)
    plt.axis('off')
    plt.legend(title="CIFAR-10 Class", loc='upper right', fontsize='small')
    plt.show()

# 7️⃣ Plot all PCA results
plot_pca(train_emb_base, train_lbl_base, "PCA – Train Embeddings (Baseline)")
plot_pca(test_emb_base,  test_lbl_base,  "PCA – Test Embeddings (Baseline)")
plot_pca(train_emb_imp,  train_lbl_imp,  "PCA – Train Embeddings (Improved)")
plot_pca(test_emb_imp,   test_lbl_imp,   "PCA – Test Embeddings (Improved)")

Final Conclusion¶

Task 3 focused on improving the quality and efficiency of training using two key strategies: sampling and mining. We then introduced PairMarginMiner to focus learning on the most informative pairs—namely, those that are hardest for the model to distinguish. These hard pairs are where the network’s predictions are most uncertain, and training on them accelerates convergence and improves generalization. The PCA plots showed that the improved model produced tighter, more separable class clusters—both in the training and testing sets—indicating a more robust and generalizable embedding space.

Across all tasks, we observed that combining a clean dataset structure with a flexible CNN encoder and targeted metric learning strategies leads to measurable improvements in both performance and interpretability. The inclusion of hard mining not only increased classification accuracy but also produced visually meaningful embedding clusters, as shown in our PCA plots.

For future work, this pipeline can be extended in several ways. One could experiment with deeper or pretrained encoders (e.g., ResNet or MobileNet), alternative loss functions such as triplet loss or proxy-based losses, and additional miners like MultiSimilarityMiner. More advanced evaluation techniques such as t-SNE or UMAP could also provide deeper insights into embedding distributions. Lastly, scaling this framework to a larger subset—or the full CIFAR-10 dataset—would help test the robustness and scalability of the approach.

In conclusion, this assignment successfully demonstrated the core principles of metric learning, showing how thoughtful dataset preparation, model architecture, sampling, and mining strategies can work together to produce a well-trained and interpretable deep similarity model.
